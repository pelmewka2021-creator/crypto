Шифр Цезаря (Caesar Cipher)

Моноалфавитный шифр замены со сдвигом символов на фиксированное число позиций.

Математическая модель

E_k(x) = (x + k) mod n (Шифрование) D_k(x) = (x - k + n) mod n (Дешифрование) Где: • x — индекс символа • k — ключ (сдвиг) • n — размер алфавита (26 для EN, 33 для RU)

Уязвимости

Сохраняет частотные характеристики языка. Взламывается частотным анализом или методом Brute-Force.

Сложность взлома: O(n) — 25 вариантов для EN, 32 для RU.

Шифр Виженера (Vigenère Cipher)

Полиалфавитный шифр замены. Использует ключевое слово для динамического сдвига символов.

Математическая модель

C_i = (P_i + K_(i mod m)) mod n P_i = (C_i - K_(i mod m) + n) mod n Где: • P_i — символ открытого текста • K_j — символ ключа • m — длина ключа

Криптоанализ

Взламывается определением длины ключа (метод Касиски, индекс совпадений) и последующим частотным анализом столбцов.

Шифровальная машина «Энигма»

Электромеханическая роторная система периода Второй мировой войны.

Компоненты устройства

  • Коммутационная панель: перестановка пар букв.
  • Роторы: динамическая смена схемы замены при каждом нажатии.
  • Рефлектор: отправка сигнала обратно через роторы. Исключает шифрование символа в самого себя.

Криптоанализ

Атака строилась на уязвимости рефлектора и применении специализированных вычислительных машин Turing Bombe.

AES (Advanced Encryption Standard)

Современный симметричный блочный шифр (размер блока — 128 бит).

Операции раунда

  1. SubBytes: нелинейная замена байтов (S-Box).
  2. ShiftRows: циклический сдвиг строк.
  3. MixColumns: перемешивание столбцов над GF(2^8).
  4. AddRoundKey: XOR с раундовым ключом.
Стойкость AES-256: 2^256 вариантов ключа. Полный перебор невозможен на существующем оборудовании.

Сравнение алгоритмов

Алгоритм Тип Размер ключа Стойкость Главная уязвимость
Цезарь Моноалфавитный 1–32 Очень низкая Частотный анализ, Brute-Force
Виженер Полиалфавитный Переменный Низкая Метод Касиски
Энигма Роторный ~77–88 бит Средняя Ограничение рефлектора, человеческий фактор
AES-256 Блочный (SPN) 256 бит Высокая Атаки по побочным каналам

Современные альтернативы

  • ChaCha20: высокоскоростной потоковый шифр.
  • RSA / ECC: асимметричные алгоритмы подписи и обмена ключами.
  • Кузнечик (ГОСТ Р 34.12-2015): блочный шифр (128 бит).
